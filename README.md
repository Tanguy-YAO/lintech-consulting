# LinTech Consulting

Ce dépôt contient une maquette de site vitrine pour l'entreprise **LinTech Consulting**. Le projet est entièrement statique et comporte une page HTML, une feuille de style CSS et un dossier d'images.

## Contenu
- `index.html` : page d'accueil présentant les services linguistiques et digitaux de l'entreprise.
- `styles.css` : feuille de style associée.
- `image_site_web/` : dossier contenant les illustrations utilisées dans la page.

## Utilisation
1. Clonez le dépôt ou téléchargez ses fichiers.
2. Ouvrez `index.html` dans votre navigateur pour afficher le site.

Les images et polices sont incluses localement, il n'y a pas de dépendances externes hormis Google Fonts.
